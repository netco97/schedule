# 🗓️ 勤務表自動化システム

## 📘 概要
このシステムは **Spring Boot + Thymeleaf** を利用して、  
勤務表（シフト表）の作成・管理を自動化するWebアプリケーションです。  
PCだけでなく、スマートフォンからもアプリのように利用できます。

---

## 🚀 主な機能
- 👤 社員ごとの勤務スケジュール管理  
- 🧾 勤務表の自動生成（シフトパターン登録対応）  
- ✏️ 勤務表の修正・保存・出力（PDF / Excel対応予定）  
- 🔐 Spring Security によるログイン認証  
- 📱 スマホ対応UI（Thymeleaf + CSS）

---

## 🛠️ 使用技術
| 分類 | 内容 |
|------|------|
| バックエンド | Spring Boot 3.5.7 |
| フロントエンド | Thymeleaf, HTML, CSS |
| セキュリティ | Spring Security |
| ビルドツール | Gradle |
| 言語 | Java 17 |
| データベース（予定） | H2 / MySQL |
